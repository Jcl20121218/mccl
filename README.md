# mccl
Beta2.0 是 MCCL2.0 的首个公开测试版本，定位为学习向启动器原型，不面向生产、日常游玩使用，主要用来展示 Minecraft 启动流程的完整实现逻辑。

本版本实现了离线账号体系、多游戏实例隔离、版本清单拉取、游戏核心下载、JVM 参数自定义、进程拉起与控制台日志输出这些核心能力。项目使用 Gson 完成 JSON 配置序列化，JNA 处理部分系统层面调用，整体代码做了模块拆分，分为账号认证、游戏构建、资源下载、配置管理几个独立包，方便其他学习者逐块阅读、调试或者拓展功能，比如后续自行接入正版登录、新增代理下载、美化 GUI 界面。

⚠️ 重要说明：Beta 版本存在已知缺陷，稳定性没有保障，可能出现下载中断、参数解析异常、进程残留、配置读取报错等问题。仓库只包含源代码，不附带 Minecraft 游戏资源、模组、资源包，相关内容需要使用者自行遵守版权规范获取。

本版本仅适合在虚拟机、测试环境中做技术验证，不建议直接用来长期游玩。所有操作仅限在你拥有完整权限的设备内进行，使用前请阅读项目免责声明，一切因运行、修改源码带来的风险，均由使用者自行承担。
