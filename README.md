# mccl
MCCL2.0 是一款基于 Java 开发的简易 Minecraft 启动器，本项目仅供编程学习与技术研究。支持离线账号登录、多实例管理、版本资源下载、自定义 JVM 参数等基础启动功能，依赖 Gson、JNA 实现配置读写与系统交互。仓库仅提供源码，不含原版游戏、模组等版权资源，相关内容需要使用者自行合规获取。代码结构清晰，模块分离，方便阅读、调试与二次开发。编译环境要求 JDK8+，推荐 IDEA 导入项目并加载 lib 下依赖。程序运行后生成 config 目录保存用户配置，分发时务必删除该目录，避免隐私泄露。使用前请阅读免责声明，仅限在本人拥有合法权限的设备测试，所有使用风险由使用者自行承担，作者不保证程序稳定，不承担任何相关责任。
