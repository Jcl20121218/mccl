可以跳过本节。
项目结构说明
src/
├─ mccl/
│  ├─ main/          # 程序入口、启动主逻辑
│  ├─ auth/          # 账号验证模块（离线验证逻辑）
│  ├─ download/      # 版本、资源下载相关逻辑
│  ├─ game/          # 游戏进程构建、JVM参数组装、命令生成
│  ├─ config/        # 配置读写、json序列化（Gson）
│  └─ ui/            # 界面相关代码（如果有GUI）
lib/                 # 第三方依赖：gson、jna
所有业务代码均放在 `src/mccl` 包下，你新增类建议遵循相同包结构，不要随意新建顶层包
，避免打包时类路径错乱。

## 核心模块简要说明

1. **入口类 Main.java**
程序启动入口，负责初始化配置管理器、加载基础设置、拉起 UI 或者控制台流程。程序启动
时会自动检测 `config` 文件夹是否存在，不存在则自动创建，**但不会自动生成玩家配置**，
配置文件在用户保存信息的时候才写入。
不要在这个类里面写大量游戏启动逻辑，它只做初始化分发，游戏启动逻辑封装在 `game` 包
内。
2. **auth 账号模块**
当前仅实现离线验证，离线 UUID 按照用户名规则生成，没有对接正版验证接口。如果你后续
想要增加正版登录，需要在这里新增验证请求逻辑，注意微软验证有 token 时效，不要硬编码
任何密钥。
3. **game 游戏启动模块（最重要）**`GameLauncher` 类负责拼装 Minecraft 启动命令：拼
接 JVM 参数、游戏主类、版本 json 里的依赖库、游戏参数、工作目录。
你可以在这里修改默认 JVM 参数、增加自定义启动标记、修改日志输出方式。
游戏进程使用 `ProcessBuilder` 启动，并且监听进程的标准输出与错误流，控制台日志转发逻
辑也在这里。
4. **config 配置模块**
基于 Gson 实现序列化和反序列化，`ConfigManager` 统一负责读写 json 配置文件。
所有用户配置（实例列表、账号信息、本地路径）都写入 `config` 目录，**代码里没有内置任
何默认个人路径、玩家 ID**，全部由运行时用户填写后保存。
如果你新增配置项，需要在对应的实体类增加字段，并且做好兼容旧配置的判断，防止旧 json 
加载时报错。
5. **download 下载模块**
负责拉取版本清单、游戏核心、资源文件，自带简单的分片重试逻辑。下载链接写在代码内为
公共官方资源地址，不含私有接口。

## 开发修改规范

- 编码格式统一使用 UTF-8，换行符推荐 LF，避免 Windows CRLF 换行带来跨平台乱码。
- 新增功能尽量拆分到独立类，不要把所有逻辑堆在 Main 中，方便后续维护。
- 测试修改代码时，不要直接使用你日常游玩的 `.minecraft` 目录，建议单独新建一个空的测
试游戏目录，防止存档或者版本文件损坏。
- 不要在源码内硬编码绝对路径、账号、UUID、密钥、token，所有可变配置全部交给配置文
件管理。

## 编译与打包说明

使用 IDEA 打包：配置 Artifact，选择从源码编译，依赖 lib 下的 jar 一起打进包或者作为外部
依赖。
命令行编译示例（仅供参考）

```
javac -cp "lib/*" -d out src/mccl/**/*.java
```

编译完成后，使用 jar 命令打包 out 目录的 class 文件，同时指定主类为 mccl.main.Main。
打包出来的 jar 运行之后，才会在同目录生成 config 文件夹。

## 二次开发限制提醒

本项目仅用于学习研究，二次修改后的版本同样需要遵守仓库附带的免责声明，不允许用于绕
过各类管控、非法分发游戏资源。
如果你分发修改后的版本，同样记得剔除运行时生成的 config 用户配置目录，不要把用户隐私
配置一并打包。

## 开发常见坑

1. 修改配置实体类之后，旧的 json 文件字段不匹配，直接抛出异常：解决方案是增加字段默
认值、增加判断，捕获解析异常。
2. 游戏启动失败：优先打印最终拼接出来的完整启动命令，单独复制命令在控制台运行，排查
参数问题。
3. 中文路径报错：Minecraft 本身对中文路径兼容性差，启动器代码仅做提示，不会自动修
复，代码内保留路径原样传递。
4. 依赖缺失：打包时忘记把 gson/jna 一起引入，运行 jar 报 ClassNotFoundException。
