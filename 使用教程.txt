# 使用教程

本项目为 MCCL2.0，一款面向学习研究用途的 Minecraft 启动器源码项目，所有操作请在
你拥有合法权限的设备环境中进行，使用前请阅读配套免责声明。
本项目仅适用于技术学习、代码调试、本地测试，请勿用于任何违反法律法规以及管理规定
的场景，一切不当使用带来的后果由使用者自行承担。

## 环境依赖

编译运行本项目，你需要提前安装 JDK 8 或者更高版本的 Java 开发工具包，配置好系统的 
Java 环境变量，推荐使用 JDK17 获得更好的兼容性。
你可以使用 IDEA、Eclipse 或者 VS Code 搭配 Java 插件打开源码文件夹，也可以使用
 javac 命令行手动编译项目源码。
项目依赖 gson、jna 第三方库，相关依赖文件放置在 lib 目录下，导入项目时请记得将 lib 
内的 jar 包添加为项目库依赖。

## 源码导入与编译步骤

1. 下载本项目源码压缩包，解压到不含中文、空格以及特殊符号的纯英文路径下，路径不要
放在桌面深层目录，避免出现读取异常。
2. 使用 Java 开发工具打开源码根目录，将 lib 文件夹中的依赖包添加到项目构建路径，确认
没有报依赖缺失错误。
3. 找到项目主入口类，一般为启动器主类文件，配置构建输出目录，推荐输出到单独的 out 文
件夹，不要和源码混在一起。
4. 执行编译操作，编译成功后可以直接在开发工具内运行调试，也可以打包为可执行 jar 文件
方便后续使用。
5. 如果你使用命令行编译，请切换到源码根目录，配置 classpath 指向 lib 依赖，再执行 
javac 编译指令，编译完成后通过 java 命令运行主类。

## 启动器基础使用说明

1. 首次运行程序时，程序会尝试自动生成配置文件夹，如果你是从源码全新启动，不会自带
玩家配置与游戏实例信息。
2. 你需要手动填写 Minecraft 游戏核心版本路径，或者使用内置的版本下载功能获取对应游
戏版本，下载资源请遵守 Minecraft 相关版权协议。
3. 在配置页面分配运行内存，建议 4GB 以上内存环境分配 2048MB 至 4096MB，内存设置
过高容易造成系统卡顿、程序崩溃。
4. 支持离线账号登录，离线模式仅适合本地单机测试，离线账号名称、UUID 仅保存在你本
地生成的配置文件中，上传分发时不要携带这类配置文件。
5. 可以新建多个游戏实例，每个实例独立保存版本、资源包、模组配置，方便切换不同的游
戏环境进行测试。

## 重要注意事项

1. config 文件夹属于程序运行之后自动生成的用户配置目录，里面包含本地路径、玩家信息
，分享、上传项目时必须排除该目录。
2. out 文件夹是编译产物目录，源码仓库不需要上传这个目录，使用者拿到源码之后可以自
行重新编译生成。
3. 模组、资源包、游戏原版资源不属于本项目，本项目仅提供启动逻辑，相关资源的获取和
使用需要遵守对应的版权要求。
4. 程序存在不确定性 BUG，测试的时候优先在虚拟机或者备份好的电脑上操作，提前备份
你的 Minecraft 存档和重要文件。
5. 本项目作者不提供稳定性承诺，遇到崩溃、报错可以自行查看控制台日志排查，项目仅作
为技术交流学习使用。

## 常见问题

Q：导入源码之后提示找不到类？
A：大概率是 lib 目录下的依赖 jar 没有添加到项目依赖库，检查项目的构建配置，重新导入
依赖包即可。
Q：运行启动器之后无法启动游戏？
A：检查游戏核心文件是否完整、Java 版本是否匹配、内存参数是否合理，同时查看控制台
输出的报错日志定位问题。
Q：能不能直接把配置文件发给别人一起用？
A：不建议，配置文件带有本地路径和个人玩家信息，直接分发存在隐私泄露风险，建议让
对方自己运行程序生成全新配置。
